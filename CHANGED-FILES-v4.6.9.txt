ROOT CAUSE
Completed ESPN soccer matches can report FT/AET rather than literal FINAL. The score ribbon
correctly suppresses postgame Green/Purple/Gold media for non-final games, so World Cup media
could be discovered and associated but still have no play arrow.

FIX
- Completed provider soccer rows use canonical FINAL.
- FT/AET provider wording is preserved separately.
- Existing persisted FT/stale SCHEDULED scored rows normalize on schedule reads.
- Background reconciliation revisits stale completion state.
- Live/today/future matches are not forced final.
- Canonical event IDs and existing media associations are preserved.
