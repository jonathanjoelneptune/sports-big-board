Recommended GitHub web upload
1. Extract the main ZIP.
2. Upload files into the repository root while preserving their paths.
3. Because GitHub/Windows folder dragging can be inconsistent, a separate Tests Upload ZIP is provided. Open the repository /tests folder, extract that ZIP locally, select all .py files, and drag the files themselves into GitHub.
4. Do not upload __pycache__ or .pyc files. None are included here.
5. Commit the complete v5.4.6 overlay and let Verify release run.
6. Replace the local Windows controller bridge folder with the separate v5.4.6 bridge ZIP and run START-CONTROLLER-BRIDGE.cmd once. The source identity changed, so it will recompile automatically.
