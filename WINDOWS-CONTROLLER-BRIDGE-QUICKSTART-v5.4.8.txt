Sports Big Board v5.4.8 Windows Controller Bridge compatibility

No local bridge update is required for v5.4.8.

Keep using the working Sports Big Board v5.4.7 Windows Controller Bridge R1. The protocol, SendInput fullscreen delivery, command-result acknowledgement, and app/video fullscreen command whitelist are unchanged in v5.4.8.

The repository overlay retains the v5.4.7 R1 helper source/launcher so a fresh install still receives the self-update-safe launcher.
