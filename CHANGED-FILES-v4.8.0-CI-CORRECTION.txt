Sports Big Board v4.8.0 — CI Release Gate Correction
=====================================================

Cause of failed GitHub Actions run #200
---------------------------------------
The v4.8.0 VERIFY.sh moved the retained v4.7 efficiency/navigation/Day State
architecture contract commands into the advisory archive. The stable
ReleaseBehaviorGate explicitly requires those current foundation contracts to
remain blocking. CI therefore failed before the JavaScript contract phase.

Correction
----------
1. Restore every command required by
   tests.test_release_behavior_gate.test_active_foundation_checker_contracts_remain_blocking
   to the blocking VERIFY.sh path.
2. Keep the v4.8.0 release number unchanged because the first v4.8.0 deployment
   never passed verification/deployed.
3. Update the retained v4.7.3-v4.7.13 JavaScript architecture tests so their
   release guard means "v4.7.N or any later 4.x release" instead of requiring
   major.minor to equal exactly 4.7.
4. Preserve every underlying behavior assertion in those tests.
5. Keep superseded v4.7 release-line implementation tests in the advisory archive.
