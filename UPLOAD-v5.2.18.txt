PRIMARY USER-VISIBLE CHANGES
- Game Center is now structured as: scoreboard hero -> full-width Overview/Team Stats/Players/Plays tabs -> one scrollable active content pane.
- Line score and win probability appear only inside Overview. The old persistent above-tabs line score is hidden.
- COMING UP is locked to the bottom of the Game Center workspace and is outside the Game Center scroll area, so it cannot bisect Team Stats/Players/Plays.
- The entire redundant player footer is removed.
- PREV and NEXT are rebuilt as plain centered text controls with no inherited icon/pseudo-content conflicts.
- The drawer collapse control is a single chevron button with no visible helper text.
- Collapsing the drawer changes the actual desktop stage grid from the normal Game Center column to a 36px handle rail; the video receives the freed width and a resize event is emitted.
- Sports Ticker keeps headline-first layout with the category as a subtle subtitle.

FUNCTIONAL BOUNDARIES
