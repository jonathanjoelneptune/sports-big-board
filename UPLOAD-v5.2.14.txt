PURPOSE
v5.2.14 is the second UI-polish pass. It focuses only on the top broadcast surface: masthead navigation, Sports Ticker, and score ribbon. Stable playback, date ownership, score ownership, Sports Ticker data/animation ownership, Game Center, media discovery, and scroll mechanics are not changed.

PREMIUM MASTHEAD
- Stronger Sports Big Board brand hierarchy.
- Fullscreen becomes a quiet circular utility control.
- Backend Inspector remains available but is visually de-emphasized.
- Date controls become compact rounded broadcast controls.
- League navigation becomes clean text tabs with a blue active underline instead of boxed buttons.
- Special Events stays in the same functional location and uses the same navigation ownership.

SPORTS TICKER
- Newsroom-style ticker label with subtle live indicator.
- More editorial headline typography and less box chrome.
- Category pills keep their news-type colors.
- Updates use quiet separators instead of individual card borders.
- Existing compositor animation, tuning values, speed, one/two-line setting, and date independence are untouched.

SCORE RIBBON
- More generous score-card typography and spacing.
- Borderless television-scoreboard rail with quiet separators.
- Stronger score numerals and team readability.
- Premium selected / Now Watching surface without expensive effects.
- Green / Purple / Gold / Blue recap availability retains subtle bottom accents.
- Previous/next date arrows become quieter edge controls.
- Existing native horizontal scrolling and score-card click behavior are untouched.

BROWSER TAB RELEASE IDENTITY
The visible browser tab is now reasserted from the canonical release identity on DOMContentLoaded and pageshow. The release verifier explicitly checks this contract in addition to the static <title>, so future releases cannot intentionally pass verification with an old tab-version label.

PERFORMANCE GUARDRAILS
- No backdrop-filter.
- No blur effects.
- No new continuous animations.
- No scroll snapping or segmented scroll points.
- No new per-frame JavaScript.
- No changes to the v5.2.10 compositor/scroll architecture.

ROLLBACK
v5.2.14 polish is isolated in ui/premium-masthead-v5214.css, loaded after ui/broadcast-design-v5213.css. Removing the v5.2.14 stylesheet link restores the v5.2.13 top-surface presentation without changing application behavior.
