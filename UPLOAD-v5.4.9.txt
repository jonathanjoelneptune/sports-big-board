Key changes
- TEAM SELECT / PLAYER SELECT is the top (12 o'clock) option in each league/event second radial.
- RT league selection is logo-first for MLB, NFL, NBA, NHL, EPL, MLS and NCAAF.
- Controller team selection waits for the canonical score-filter league context before opening history.
- If a targeted team audit returns no rows, controller selection performs one bounded league-wide recovery scan and filters the same historical catalog locally.
- Team/player history still uses the canonical Browse timeline and automatically starts the newest playable game, preserving the normal chronological playlist behavior.
- Participant metadata is now complete-league and persistent: backend directories seed all known teams with abbreviations/logos rather than only teams encountered in playable history.
- Browser participant catalogs use stale-while-refresh: 12-hour freshness, up to 90 days immediately usable, with background refresh.
- Core and special-event participant catalogs are prewarmed after startup.
- A cold/empty participant directory keeps a visible loading/retry radial instead of silently closing.
