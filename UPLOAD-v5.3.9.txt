USER-VISIBLE CHANGES
- Opening a Team Browse context now automatically starts the newest playable team highlight and builds the older-history queue behind it.
- The right Team Focus controls match the compact top-menu action styling and read Play All and Exit Event.
- GAME CENTER, LEAGUE VIEW, and SETTINGS are mutually exclusive drawer views. League View or Settings fully replaces Game Center instead of leaving Game Center rendered beneath the selected pane.
- Team Browse rows now show a white-backed logo tile and the full team name only. The redundant second three-character abbreviation chip is removed.
- Team and focus logos receive white-backed tiles so dark or transparent marks stay visible across team themes.
- A selected Special Event remains visible in the main sports row for the life of the context. Example: SPECIAL EVENTS → FIFA WC → TEAM BROWSE → EXIT EVENT. The event chip is repaired automatically if the score-filter row rerenders.
- League View follows the sport/event actually being played. A score-card interrupt or MLB recap switches League View to MLB instead of leaving a previously browsed World Cup context active.
- Team Sports Ticker cells are centered, content-sized, and use less horizontal padding so short items such as STREAK do not consume oversized space.

PLAYBACK PAUSE FIX
- Explicit user pause is now a persistent, selection-scoped state instead of a 12-second suppression window.
- The ~5-second early-pause watchdog still provides one soft resume and one bounded recovery for genuine unexpected pauses.
- Once the user intentionally pauses, the watchdog cannot restart that same selection until the user explicitly resumes or a different selection takes ownership.
- YouTube/provider control interaction is detected through iframe focus so a pause performed on embedded provider controls is also treated as user intent.
