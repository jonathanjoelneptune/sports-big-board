KEY v5.0.0 BEHAVIOR
-------------------
- Score playback intent exists before media lookup or prewarm can wait/fail.
- Event selection + playback intent are one atomic App Store reducer transition.
- Prewarm timeout ends the transaction UNAVAILABLE without losing Selected Event.
- Historical score clicks create a transaction before on-demand media search.
- Game Center cannot be redirected by active media/player callbacks.
- Launch Game Center follows the already-selected event under v5.
- All normal PlaybackController tune calls route through tuneProgramIndexV5().
- Hot A/B standby promotions route through promotePreparedV5().
- Existing A/B implementation binds once as the v5 legacy player adapter.
- Playback Session v2.0 can represent PREPARING intent with no media selected yet.
- Comprehensive Certification schema 3.0 reports App Store, transaction,
  adapter binding, event ownership and v5 invariant.

INTENTIONALLY NOT REBUILT IN 5.0.0
---------------------------------
- SQLite catalog / 27k+ verified media inventory
- Day State / score ribbon data path
- historical discovery / workers
- media tier taxonomy and Event Matcher
- provider acquisition stack
- existing A/B player mechanics beneath the adapter boundary
