## Structure

`assets/soundtrack/tracks/` contains normalized unique MP3s.

`assets/soundtrack/manifest.json` is player-ready and includes a shuffle-bag configuration so a track is not repeated until the full bag has been exhausted.

`soundtrack-inventory.csv` is the human-readable inventory for later auditioning and pair-down.

## Tier intent

- **CORE**: strongest/highest-frequency sports-highlight candidates.
- **ROTATION**: tracks from the previously selected Sports Big Board longlist.
- **REVIEW**: additional unique tracks from the upload. They are intentionally retained rather than discarded so the final library can be paired down after listening.

No audio has been transcoded or altered; only exact duplicate file content was removed and filenames were normalized.
