WHAT v5.3.0 ADDS
- Selecting a league exposes one user-facing BROWSE control in the normal top navigation.
- BROWSE offers TODAY'S <LEAGUE>, ALL <LEAGUE> HIGHLIGHTS, and team/player search.
- Team sports search by team; tennis search by player.
- NCAAF adds RANKED TODAY; tennis adds SEEDED TODAY.
- Historical team/player results come from the same /api/history/audit catalog used by Database Audit.
- Historical results are sorted reverse chronologically and use the best verified media package known for each game/match.
- A filtered media ribbon replaces the daily score ribbon only while Browse mode is active.
- Each result is visual/thumbnail-first and can be played immediately or added to a selected subset.
- PLAY ALL queues the entire filtered result set. Selecting cards changes the action to PLAY SELECTED (N).
- Favorites are stored locally and appear at the top of Browse.
- Curated programming uses the existing PROGRAM + PlaybackController path; there is no second playback engine.
- Score-ribbon selections retain the v5.2.20 interrupt/resume behavior when a curated queue is running.
