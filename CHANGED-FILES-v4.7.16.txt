Sports Big Board v4.7.16 — Doubleheader Identity & CFB Playlist Contract
Base release: v4.7.15

WHY THE "DUPLICATES" APPEARED
- ARI/SF and BOS/NYY on 2026-08-29 were legitimate MLB doubleheaders, not duplicate schedule rows.
- The ribbon did not distinguish the two games, so they appeared duplicated.
- A separate correctness defect allowed stale media already associated under older catalog rules to surface for the wrong game date. The observed example was an August 28 ARI/SF recap offered while browsing August 29.

WHAT v4.7.16 CHANGES
1. Doubleheader identity
   - Same-day repeated matchup with distinct event IDs is labeled GAME 1 / GAME 2 in scheduled-time order.
   - Exact repeated canonical event IDs are defensively suppressed at presentation time.
   - No canonical schedule rows are deleted or merged.

2. MLB recap-date firewall
   - Browser score-card playback rejects an MLB media asset when its title explicitly names a date different from the score event date.
   - Day State revalidates persisted EVENT_MEDIA relationships against the current evidence matcher before publishing eventPlans.
   - The same physical YouTube/direct asset cannot satisfy multiple same-day canonical games unless provider event/game identity proves one unique owner.

3. College Football playlist enforcement
   - CFB Purple/Extended playlist: Full Game Highlights | 2026-27
   - Playlist ID: PLPydJJjt7Pb4
   - Source: ESPN College Football
   - Season bounds: 2026 through 2027 (preserves January postseason coverage)
   - Objective: Extended / Purple
   - Priority: PRIMARY
   - Required title phrase: "full game highlights" (case-insensitive)
   - Source metadata is now preserved through operator-playlist normalization and crawler conversion.
   - Playlist enrollment/repair runs at server startup and during normal CFB refresh.

4. v4.7.15 efficiency architecture preserved
   - All-league card-bank filter fast path retained.
   - Generation-scoped availability snapshot reuse retained.
   - Stabilized DOM certification retained.
   - Efficiency modules only receive the 4.7.16 release identity; their algorithms are unchanged.
