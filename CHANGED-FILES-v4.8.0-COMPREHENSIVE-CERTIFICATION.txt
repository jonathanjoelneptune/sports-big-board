WHAT v4.8.0 CHANGES
1. Comprehensive Certification schema 2.0 is game-agnostic and seeded/replayable.
2. The whole-site run now actively exercises real score-card playback instead of
   passively observing whatever video happened to be active.
3. Playback coverage spans multiple dates and prioritizes unseen leagues and
   Green/Purple/Blue media tiers where those tiers are available.
4. Certification requires actual transport-clock progress, not only provider
   PLAYING state or optimistic first-frame session state.
5. Game Center sampling is seeded and round-robin across available leagues; there
   are no USC, San Jose State, or specific event-ID branches in the comprehensive
   architecture.
6. Game Center UI interaction checks exercise Overview, Team Stats, Players, and
   Plays and restore the prior state afterward.
7. A dedicated production Playback Progress Watchdog fixes the non-advancing-player
   class globally: soft play kick at 3.5 s, canonical recovery/fallback at 8 s.
8. Comprehensive reports include the seed, active playback matrix, first progress,
   fallback hops, watchdog evidence, API/backend state, workers, discovery, Game
   Center census, efficiency metrics, and actionable failures.
9. Efficiency Certification now reports the current v4.8.0 release label.
10. v4.8 establishes a new blocking certification line. Stable behavior contracts
    and v4.8 tests block deployment; v4.7 release-line tests remain diagnostic
    advisory evidence so obsolete 4.7-only version assertions cannot reject 4.8.
11. Foundation Certification remains a retained baseline. Its live runtime contract
    still blocks deployment, but its historical manifest no longer has to be
    rewritten merely because Comprehensive Certification advances the release line.

Board, enable Dev Mode, and run COMPREHENSIVE SITE CERTIFICATION. Save the full
report including its SEED. If a run exposes a failure, re-run the same seed to

additional broad coverage.
