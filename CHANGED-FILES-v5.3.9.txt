PRIMARY v5.3.9 RUNTIME CHANGES
- Team Browse automatically starts the newest playable recap when a team context opens.
- Team Focus actions use the compact masthead action style and exact labels Play All / Exit Event.
- League View and Settings are exclusive drawer panes; hidden Game Center content no longer remains visible underneath them.
- Team Browse rows use a white-backed logo tile + full team name; the redundant second abbreviation chip is removed.
- Active Special Event chips persist across score-filter/ribbon rerenders and use compact event labels such as FIFA WC.
- Manual pause is selection-scoped and persistent. The early-pause watchdog no longer resumes an intentional user pause after a timeout, including provider-control pauses detected through iframe focus.
- League View resolves context from the currently selected/playing event before retained special-event navigation context, so an MLB recap shows MLB League View even after browsing World Cup.
- Team Sports Ticker cells are centered and content-sized with reduced horizontal padding.
