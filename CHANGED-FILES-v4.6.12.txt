FEATURES
1. COPY TEMPLATE JSON button in the Competition Builder schedule step.
2. Generic reusable special-event JSON format with rich participant aliases/groups and provider metadata.
3. Required title phrases and excluded title phrases for Green/Purple/Blue playlist sources.
4. Same title-rule fields available from Historical Database > Game Media Playlists for existing custom events.
5. Required phrase matching is OR-based; any excluded phrase rejects the candidate before association.
6. Imported participant aliases/group/abbreviation values are tried as additional event-match evidence.
7. Updating media rules persists them to the custom competition and starts a force recrawl.
8. LLWS defaults Green required title phrase to "Full Game Highlights"; operators can change or clear it.
9. Existing source media is preserved; rules affect association eligibility, not source-media retention.
