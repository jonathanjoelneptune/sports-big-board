Sports Big Board v4.2.1 — Milestone 1 Hardening

This release is the first stress-test-driven hardening pass for Milestone 1. It addresses the production findings from the v4.2.0 Milestone Release Console rather than adding product surface area.

Key corrections:
- Historical discovery is date-scoped and bulk-loads event state instead of issuing per-game event reads.
- Hot diagnostic/operator endpoints use compact summaries and cached integrity data instead of nesting whole-catalog integrity work.
- Read-only operator/audit repository methods use independent query-only SQLite connections and do not wait on the process-wide writer lock.
- Operator telemetry refreshes independent components on staggered TTLs and serves the last completed snapshot while expensive components refresh.
- Schedule sync starts with a bounded near-term horizon and heartbeats before/after every league/date step, then defers the full horizon.
- Director AI cannot block the UI request path: deterministic ranking returns immediately and AI enrichment is background/cached.
- Stress pause/resume tests command desired state explicitly, eliminating the false failure seen when a test starts from an already-paused player.
- Scheduler diagnostics classify timeout/not-found/parse/rate-limit/provider/cancelled errors and retain recent examples.
- Milestone Console surfaces operator component failures instead of allowing a failed refresh to be silent.

No catalog rebuild. No soundtrack re-upload.
